## 👨‍💻 Sobre mí

Soy estudiante de **quinto semestre de Ingeniería de Sistemas en la Universidad Central**, con interés en el **desarrollo de software, análisis de datos y bases de datos**.

Durante mi formación académica he desarrollado conocimientos en programación, desarrollo web, gestión de bases de datos y herramientas para el análisis y gestión de información.

Me interesa utilizar la tecnología para:

- 💻 Desarrollar soluciones mediante programación.
- 📊 Transformar datos en información útil.
- 🔎 Identificar patrones y analizar información.
- ⚙️ Automatizar procesos.
- 🗄️ Gestionar y trabajar con bases de datos.
- 🚀 Crear soluciones tecnológicas eficientes.

Actualmente busco seguir fortaleciendo mis habilidades mediante **proyectos, prácticas, oportunidades de aprendizaje y posiciones junior** relacionadas con tecnología.
